# JanSamadhan 2025

JanSamadhan is a comprehensive citizen issue reporting and tracking platform. It empowers citizens to easily report local issues (like potholes, broken streetlights, water supply problems, etc.) and allows administrators and field staff to track, assign, and resolve them efficiently.

## Key Features
- **Interactive Map:** View reported issues geographically. Search for any area or city to instantly see nearby issues.
- **Easy Reporting:** Citizens can report issues with photos, descriptions, and automatic location tagging.
- **Role-Based Access:** Dedicated portals for Citizens, Field Staff, and Administrators.
- **Multilingual Support:** Accessible in English, Hindi, and Telugu.
- **AI Analysis:** Automatically analyzes reported issues to suggest categories and severity using Gemini AI.
- **Real-Time Tracking:** Citizens can track the progress of their reported issues from submission to resolution.

## Getting Started

1. Install dependencies:
   `npm install`
2. Set the `VITE_GEMINI_API_KEY` in `.env` to your Gemini API key
3. Run the app:
   `npm run dev`
4. END !!
